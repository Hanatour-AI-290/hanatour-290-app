# 협업 규칙

## 브랜치

- `main` 에 바로 push 하지 않고 PR 로만 합친다. CI(lint + test) 통과가 조건.
- 브랜치 이름: `feat/fe-영수증화면`, `feat/be-정산api`, `feat/ai-줄단위읽기`, `fix/...`

## 커밋 메시지

`[접두어] 무엇을 했는지` - 한국어로.

| 접두어     | 쓰는 때                 |
| ---------- | ----------------------- |
| `[Add]`    | 기능 추가               |
| `[Fix]`    | 버그 수정               |
| `[Refactor]` | 동작 그대로, 구조 정리 |
| `[Docs]`   | 문서                    |
| `[Chore]`  | 설정·의존성             |

## 비밀값

- API 키는 `.env` 에만. `.env.example` 에는 키 **이름**만 적는다.
- 공개 저장소라서 실수로 올렸으면 바로 키를 폐기하고 새로 발급한다.

## 데이터 형식을 바꿀 때

`packages/shared/src/schemas.js` 를 고치면 `docs/api.md` 도 같이 고치고, PR 설명에 적는다.
