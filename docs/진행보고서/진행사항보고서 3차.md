## 2. 지금 상황

- 코드: 1번 내용은 전부 `feat/be`에 커밋함. `main`에는 아직 안 들어감
- 배포: hanatour-290.vercel.app 은 아직 예전 프로토타입 (`/api/settle` 404)
- 로컬: AI 키 없음. 결제자 여러 명은 AI 응답을 가짜로 넣어 화면·정산까지 확인함

## 3. 아직 안 된 것

1. 실제 AI로 확인 못 한 것
   - 영수증 줄 단위 읽기(FR-007), 말로 나누기와 결제자 여러 명(FR-008), 영수증 분류(FR-018), 배정 다시 정하기(FR-009)
   - 이유: 로컬에 키가 없고, 배포본에는 이 API가 없음
   - 해결: Vercel 재배포 후 배포 사이트에서 확인
2. 정확도 측정 (PER-001)
   - 문장 20개는 준비됨. 영수증은 10장 중 1장뿐
   - 해결: 영수증 9장과 정답 추가, 키가 있는 환경에서 `npm run eval`, `npm run eval:sentences` 실행
