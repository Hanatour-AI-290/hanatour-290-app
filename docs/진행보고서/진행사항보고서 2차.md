## 2. 지금 상황

- 코드: 전부 `feat/be`에 있음
- 배포: hanatour-290.vercel.app 은 아직 예전 프로토타입. `feat/be`로 다시 배포해야 새 기능이 보임
- 로컬: 해커톤 키는 뺐고, 상품 분석과 기록 요청은 배포본(팀원 키)으로 넘겨서 동작

## 3. 아직 안 된 것

1. 영수증 줄 단위 분석, 말로 줄별 나누기
   - 코드는 있는데 실제로 돌려 보지 못함. 배포본에 이 API가 없어서 팀원 키로 못 돌림
   - 해결: Vercel 다시 배포 (조창래 님)
2. 정확도 측정 (PER-001)
   - 로컬에 키가 있어야 하고, 평가용 영수증이 1장뿐
   - 해결: 팀원 키를 로컬 `.env`에 넣고, 영수증 사진 9장과 정답 추가
