## 3. 인수인계 (남은 일은 조창래 님이 맡음)

### 3-1. 배포

- 배포 기준: `main` 최신 커밋 `fa6c4de`. Vercel 설정은 저장소의 `vercel.json` 그대로 (빌드 `npm run build`, 화면 `apps/web/dist`, 서버 `api/[[...route]].js`)
- Vercel 환경변수

| 이름 | 값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 조창래 님 키 (해커톤 키 대신 쓰기로 함) | 없으면 AI 기능 전부 실패 |
| `ANTHROPIC_WORKSPACE_ID` | 워크스페이스 키일 때만 | 일반 키면 비움 |
| `AI_MODEL` | 비워도 됨 | 비우면 `claude-opus-5-5` |
| `AI_UPSTREAM` | 비움 | 키가 없는 로컬에서 배포본으로 넘길 때만 씀. 키가 있으면 무시됨. 키 없이 이 값만 자기 주소로 들어가면 503 |
| `CORS_ORIGIN`, `PORT`, `LOG_LEVEL` | 비움 | 로컬 개발용. 배포본은 화면과 API가 같은 주소라 필요 없음 |

- 배포 확인: `https://(주소)/api/health` 에서 `{"ok":true}` 가 나오면 새 버전. 404면 예전 버전
- 키는 Vercel 환경변수와 각자 PC의 `.env`(커밋 안 됨)에만 둠 (보안 1)

### 3-3. 정확도 측정 (PER-001)

- 준비된 것: 문장 20개 (`packages/ai/eval/sentences.json`), 영수증 1장 (`packages/ai/eval/cases/001.jpg`, `001.json`)
- 남은 것: 영수증 9장 + 정답 JSON. 요구사항은 영수증 10장 × 말 2개라 JSON은 총 20개 (`002a.json`, `002b.json` → `002.jpg` 식)
  - 형식은 `packages/ai/eval/cases/README.md`. 금액은 최소 단위 정수 (₺2.600,00 → `260000`)
  - 실제 이름·카드 번호가 보이는 영수증은 가리고 넣음 (공개 저장소)
- 실행: 저장소 루트에 `.env` 만들고 (`.env.example` 복사) `ANTHROPIC_API_KEY` 채운 뒤

```bash
npm ci
npm run eval                 # 영수증, 재시도 켬
npm run eval -- --no-retry   # 영수증, 재시도 끔
npm run eval:sentences       # 문장 20개
```

- 결과: 화면에 표가 나오고 `packages/ai/eval/results/` 에 JSON으로 저장됨. 지표 설명은 `cases/README.md`
- 측정 결과를 보고서와 PPT에 넣음
