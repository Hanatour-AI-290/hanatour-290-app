## 3. 실행 방법

```bash
npm install
cp .env.example .env    # ANTHROPIC_API_KEY 또는 AI_UPSTREAM=https://hanatour-290.vercel.app/api
npm run dev             # 화면 http://localhost:5173
npm test
```

시연 전에 리포트 탭 맨 아래 "시연 처음 상태로 되돌리기" 를 누르면 여행 3일째 상태로 시작한다.
