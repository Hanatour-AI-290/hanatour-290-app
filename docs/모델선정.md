> 작성 2026-11-04 · 관련 문서: 요구사항정의서(FR-001~023, R-24~26)

## 1. 결론

| 구분 | 내용 |
|---|---|
| 현재 기본값 | **Claude Sonnet 5.5** (`claude-sonnet-5-5`) - 팀 저장소의 `.env.example`과 `packages/ai/src/client.js`에 설정된 값 |
| 비교 후보 | Claude Opus 5.5 (`claude-opus-5-5`, 더 비쌈), Claude Haiku 5.5 (`claude-haiku-5-5`, 더 쌈) |
| 확정 방법 | `npm run eval`(R-26 정확도 측정, 7장)에서 같은 케이스로 세 모델을 비교해 정한다 |
| 바꾸는 방법 | 코드는 그대로 두고 `.env`의 `AI_MODEL` 값만 바꾼다 |

핵심 기능(FR-007~009: 영수증 줄 단위 읽기 + 말로 나누기 + 규칙 검증 후 재시도)은 이미지 읽기와 판단을 함께 해야 해서 정확도가 가장 중요하다. 정확도가 Sonnet 5.5로 부족하면 Opus 5.5로 올리고, 충분하면 Haiku 5.5로 내려도 되는지 확인한다.

## 2. 후보 모델 비교

모델 정보는 2026-11-04에 해커톤 API 키로 Anthropic Models API(`GET /v1/models`)를 조회한 결과이고, 가격은 Anthropic 가격표(2026-10-06 기준 자료)다. 가격은 1백만 토큰당 미국 달러.

| 항목 | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
|---|---|---|---|
| 모델 ID | `claude-opus-5-5` | `claude-sonnet-5-5` | `claude-haiku-5-5` |
| 입력 가격 | $4.00 | $2.00 | $0.10 (10만 토큰 초과 시 $0.50) |
| 출력 가격 | $20.00 | $10.00 | $0.50 (10만 토큰 초과 시 $2.50) |
| 캐시 읽기 | $0.20 | $0.20 | - |
| 입력 한도 | 1,000,000 토큰 | 1,000,000 토큰 | 1,000,000 토큰 |
| 출력 한도 | 128,000 토큰 | 128,000 토큰 | 128,000 토큰 |
| 이미지 입력 | 지원 | 지원 | 지원 |
| 구조화 출력 | 지원 | 지원 | 지원 |
| 생각(thinking) 끄기 | 불가 (effort로만 조절) | `between_tools`로만 가능 | 가능 |
| effort 기본값 | medium | high | medium |

참고: 가장 성능이 높은 Claude Fable 5.1(`claude-fable-5-1`)은 입력 $10 / 출력 $50으로 Opus 5.5보다 비싸서 후보에서 뺐다.

## 3. 우리 서비스의 AI 작업

| 요구사항 | 작업 | 입력 | 난이도 |
|---|---|---|---|
| FR-007 | 영수증 메뉴·수량·금액·세금을 줄 단위로 읽고 현지어 메뉴 번역 | 이미지 | 높음 |
| FR-008 | “맥주는 하린이랑 도윤, 서준은 술 빼고”를 해석해 줄마다 낼 사람 배정, 결제자 여러 명 | 이미지 + 문장 | 높음 |
| FR-009 | 서버가 찾은 틀린 점을 받아 한 번 다시 읽기 | 이미지 + 문장 + 오류 목록 | 높음 |
| FR-001 | 상품 문구에서 선택관광·가이드 경비·불포함 항목 추출, 근거 원문 표시 | 긴 문장 | 중간 |
| FR-015, 016 | 문장·카드 문자에서 금액·통화·결제 수단 읽기 | 짧은 문장 | 낮음 |

모든 작업은 정해진 형식(JSON)으로 결과를 받아야 하므로 구조화 출력이 필요하고, 세 후보 모두 지원한다. 계산(나누기·환산·차감)은 AI가 아니라 서버 계산 함수가 한다(R-24).

## 4. 선정 기준

1. **정확도**: R-26 지표(줄 금액 일치율, 배정 정답률, 오류를 잡아낸 비율)
2. **형식 고정**: 구조화 출력으로 항상 같은 모양의 결과를 받는지
3. **응답 속도**: 시연 중 영수증 한 장을 처리하는 시간
4. **비용**: 해커톤 크레딧은 잔액을 일반 API 키로 조회할 수 없어 총량을 모른다. 측정에서 요청 1건당 토큰 수(`usage`)를 기록해 비교한다.

## 5. 모델별 API 주의 사항

코드를 짤 때 아래를 지키지 않으면 400 오류가 난다.

| 항목 | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
|---|---|---|---|
| `thinking: {type: "disabled"}` | 400 오류 | 400 오류 (`between_tools` 사용) | 사용 가능 |
| `budget_tokens` | 400 오류 | 400 오류 | 400 오류 |
| `tool_choice`를 `any`/`tool`로 강제 | 400 오류 | 400 오류 | - |
| 마지막 assistant 메시지 미리 채우기(prefill) | 400 오류 | 400 오류 | 400 오류 |

공통으로 지킬 것:
- 결과 형식은 `output_config.format`(구조화 출력)으로 고정한다. 옛 `output_format` 파라미터는 쓰지 않는다.
- 응답을 쓰기 전에 `stop_reason`을 확인한다. `"refusal"`이면 AI가 처리를 거절한 것이므로, 직접 입력 화면(FR-017)으로 넘긴다.
- 생각의 깊이는 `output_config: { effort: "low" | "medium" | "high" }`로 조절한다. Opus 5.5는 기본값이 medium이라 원하는 값을 명시한다.

## 6. 적용 방법

팀 저장소(`hanatour-290-app`)에는 이미 모델을 환경변수로 바꾸는 구조가 있다. 측정 결과에 따라 `.env`의 `AI_MODEL`만 바꾸면 된다.

```
# 저장소 루트의 .env (cp .env.example .env) - 절대 커밋 금지
ANTHROPIC_API_KEY=...
AI_MODEL=claude-sonnet-5-5
```

`packages/ai/src/client.js`의 현재 코드:

```js
export const MODEL = process.env.AI_MODEL ?? 'claude-sonnet-5-5'
```

AI 호출 예시 (`packages/ai`에서 구조화 출력으로 결과 형식을 고정):

```js
import { zodOutputFormat } from '@anthropic-ai/sdk/helpers/zod'
import { getClient, MODEL } from './client.js'

const r = await getClient().messages.parse({
  model: MODEL,
  max_tokens: 4000,
  messages: [{ role: "user", content }],      // 영수증 이미지 + 말
  output_config: { format: zodOutputFormat(ReceiptSchema), effort: "medium" },
});
if (r.stop_reason === "refusal" || !r.parsed_output) {
  // 직접 입력 화면(FR-017)으로
}
```

## 7. 확정을 위한 측정 계획 (R-26)

| 항목 | 내용 |
|---|---|
| 실행 | `npm run eval` (`packages/ai/eval/run.js`). 채점 로직은 아직 구현되지 않았다(TODO) |
| 데이터 | 예시 영수증 10장 × 말 2개 = 20건, 문장(카드 문자·현금 지출) 20개 |
| 케이스 형식 | `packages/ai/eval/cases/`에 영수증 이미지와 정답 JSON 한 쌍 (`001.jpg` + `001.json`: `utterance`, `members`, `expected.lines`, `expected.splits`) |
| 정답 | 영수증 줄별 금액과 줄마다 낼 사람을 사람이 미리 적어 둔다. 공개 저장소라 실제 이름·카드번호는 가린다 |
| 비교 대상 | Opus 5.5 / Sonnet 5.5 / Haiku 5.5, 각각 effort low·medium |
| 재시도 | FR-009 재시도를 켰을 때와 껐을 때 모두 측정 |

| Opus 5.5 | low | 켬 | | | | | |

확정 규칙:
- 현재 기본값(Sonnet 5.5)과 배정 정답률이 같은 수준이면 더 싼 모델을, 부족하면 Opus 5.5를 쓴다.
- 영수증 작업(FR-007~009)과 짧은 문장 작업(FR-015, 016, 018)의 결과가 다르게 나오면, 작업별로 모델을 나누는 것도 검토한다.
- 측정 결과표는 발표 장표에 그대로 쓴다(R-26).
