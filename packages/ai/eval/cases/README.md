# 평가 케이스 (PER-001)

케이스 하나 = 영수증 이미지 + 정답 JSON 한 쌍.

```
cases/
  001.jpg
  001.json
```

```json
{
  "image": "001.jpg",
  "utterance": "차는 하린이랑 도윤만, 나머지는 다 같이",
  "me": "지우",
  "members": [{ "id": "m1", "name": "지우" }, ...],
  "expected": {
    "total": 356000,
    "lines": [{ "name": "TESTİ KEBABI", "qty": 4, "total": 260000 }, ...],
    "splits": [{ "lineIndex": 3, "memberIds": ["m2", "m3"] }]
  }
}
```

- 금액은 최소 단위 정수 (TRY 2.600,00 → `260000`). 세금 줄은 `"kind": "tax"`
- `splits` 에 없는 메뉴 줄은 전원(1/N)이 정답
- 실제 사람 이름·카드번호가 보이는 영수증은 가리고 넣기 (공개 저장소)
- 요구사항은 영수증 10장 × 말 2개. 같은 사진에 말을 다르게 하려면 JSON 을 두 개 만들고 같은 `image` 를 가리킨다 (예: `002a.json`, `002b.json` → `002.jpg`)

## 실행

```bash
npm run eval                 # 재시도 켬
npm run eval -- --no-retry   # 재시도 끔 (켬/끔 비교)
```

`.env` 의 `ANTHROPIC_API_KEY` 가 있어야 하고, 모델은 `AI_MODEL` 을 바꿔 비교한다. 결과는 `eval/results/날짜_모델_retry.json`.

| 지표 | 계산 |
| ---- | ---- |
| 줄 금액 일치율 | 정답 줄 중 같은 금액의 줄을 읽은 비율 |
| 합계 일치율 | 영수증 합계를 맞게 읽은 케이스 비율 |
| 배정 정답률 | 정답 메뉴 줄 중 나눌 사람이 정확히 같은 비율 |
| 잡아낸 비율 | 틀린 케이스 중 서버 검사 실패나 질문으로 표시된 비율 |
| 평균 시간 | 케이스당 초 |

## 문장 20개 (`eval/sentences.json`)

말 15개 + 카드 문자 5개를 `readRecord` 로 돌린다. 정답은 문장에 적힌 값만 쓰고, 금액이 없는 문장은 `"amount": null` 이 정답이다 (추측 금지).

```bash
npm run eval:sentences
```

| 지표 | 계산 |
| ---- | ---- |
| 금액 일치율 | 금액과 통화를 맞게 읽은 비율 (금액 없는 문장은 비워 둔 게 정답) |
| 결제자 정답률 | 결제자(여러 명이면 이름과 금액 모두)가 같은 비율 |
| 나눌 사람 정답률 | 나눌 사람 목록이 정확히 같은 비율 |
| 분류 일치율 | 식사·선택관광·교통·쇼핑·팁·기타가 같은 비율 |
| 잡아낸 비율 | 틀린 것 중 금액을 비워 둬서 직접 입력으로 넘어간 비율 |

결제자·나눌 사람을 비우면 화면이 말한 사람으로 채우므로 그렇게 보고 채점한다. 말·문자 기록에는 재시도가 없어서 켬/끔 비교는 영수증 측정에서만 한다.
